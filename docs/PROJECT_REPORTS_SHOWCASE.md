# 项目报表分析模块 - 功能展示

## 📊 模块概览

项目报表分析模块提供了**4大类、16种**数据可视化图表，全面覆盖项目的进度、工时、团队和质量四个维度。

### 报表类型分布

```
┌─────────────────────────────────────────────────┐
│              项目报表分析模块                     │
├─────────┬─────────┬─────────┬─────────┬─────────┤
│ 进度报表 │ 工时报表 │ 团队报表 │ 质量报表 │   合计   │
├─────────┼─────────┼─────────┼─────────┼─────────┤
│   4种   │   4种   │   4种   │   4种   │  16种   │
└─────────┴─────────┴─────────┴─────────┴─────────┘
```

## 🎨 图表类型

### 1. 折线图 / 面积图
- **迭代完成率趋势**（面积图）
- **工时投入趋势**（面积图）
- **缺陷数量趋势**（折线图）
- **成员活跃度趋势**（面积图）

**用途**：展示数据随时间的变化趋势

### 2. 饼图
- **任务状态分布**（环形饼图）
- **缺陷类型分布**（饼图）

**用途**：展示数据的占比分布

### 3. 柱状图 / 堆叠柱状图
- **成员工时投入排行**（柱状图）
- **工时分布（按迭代）**（柱状图）
- **成员任务分布**（堆叠柱状图）
- **成员负载分析**（柱状图 + 热力图）
- **缺陷修复时效**（柱状图）
- **缺陷密度**（柱状图 + 热力图）

**用途**：对比不同类别的数据大小

### 4. 散点图
- **预计完成时间分析**（气泡散点图）
- **预估工时 vs 实际工时**（散点图）

**用途**：展示两个变量之间的关系

### 5. 甘特图
- **里程碑达成情况**（甘特图）

**用途**：展示项目时间线

### 6. 雷达图
- **成员贡献度排行**（雷达图）

**用途**：多维数据对比分析

## 📈 数据指标

### 进度指标
| 指标 | 说明 | 用途 |
|------|------|------|
| 迭代完成率 | 已完成迭代占总迭代的比例 | 评估整体进度 |
| 任务状态分布 | 待办/进行中/已完成的任务数 | 了解任务分配 |
| 里程碑达成情况 | 各迭代的起止时间和状态 | 识别延期风险 |
| 预计完成时间 | 未完成任务的计划完成时间 | 优化资源分配 |

### 工时指标
| 指标 | 说明 | 用途 |
|------|------|------|
| 成员工时投入 | 每个成员的总工时 | 识别高贡献成员 |
| 工时趋势 | 每天的工时投入 | 分析工作节奏 |
| 预估vs实际 | 任务预估工时和实际工时对比 | 评估估时准确性 |
| 工时分布 | 各迭代的工时投入 | 优化迭代规划 |

### 团队指标
| 指标 | 说明 | 用途 |
|------|------|------|
| 成员任务分布 | 每个成员的任务状态分布 | 识别负载不均 |
| 成员贡献度 | 完成任务数 + 投入工时 | 评估成员表现 |
| 成员负载 | 进行中任务数 | 预防团队疲劳 |
| 成员活跃度 | 每天有工时记录的成员数 | 提升团队凝聚力 |

### 质量指标
| 指标 | 说明 | 用途 |
|------|------|------|
| 缺陷数量趋势 | 每天新增缺陷数 | 识别质量波动 |
| 缺陷类型分布 | 不同严重程度的缺陷占比 | 制定改进计划 |
| 缺陷修复时效 | 缺陷的修复时长 | 评估响应速度 |
| 缺陷密度 | 缺陷数占任务数的比例 | 识别薄弱环节 |

## 🎨 颜色编码

### 状态颜色
```
绿色 (#52c41a) ────────► 已完成 / 正常 / 低负载
蓝色 (#1890ff) ─────────► 进行中 / 默认
橙色 (#faad14) ─────────► 待办 / 警告 / 中负载
红色 (#f5222d) ──────────► 严重 / 危险 / 高负载
灰色 (#d9d9d9) ─────────► 未开始 / 禁用
紫色 (#722ed1) ─────────► 辅助数据
```

### 图表主题
- **主色调**：蓝色系（专业、稳重）
- **辅助色**：绿色、橙色、红色（状态区分）
- **渐变**：面积图使用渐变填充（视觉效果）

## 💡 使用场景

### 场景1：周会汇报
```
1. 打开项目详情页
2. 点击"报表" → "进度报表"
3. 时间范围选择"本周"
4. 查看"迭代完成率趋势"和"任务状态分布"
5. 截图或导出（开发中）
```

### 场景2：月度复盘
```
1. 打开项目详情页
2. 点击"报表" → "工时报表"
3. 时间范围选择"本月"
4. 查看"成员工时投入排行"和"工时投入趋势"
5. 识别高贡献成员
```

### 场景3：质量分析
```
1. 打开项目详情页
2. 点击"报表" → "质量报表"
3. 时间范围选择"本季度"
4. 查看"缺陷类型分布"和"缺陷密度"
5. 制定改进计划
```

### 场景4：团队优化
```
1. 打开项目详情页
2. 点击"报表" → "团队报表"
3. 查看"成员负载分析"和"成员贡献度排行"
4. 识别过载成员
5. 调整任务分配
```

## 🔧 技术亮点

### 1. 响应式设计
- 桌面端：2列布局，图表高度 320px
- 平板端：自适应布局
- 移动端：1列布局，图表高度 280px

### 2. 性能优化
- 按需加载图表（仅渲染当前报表类型）
- 数据分页（限制显示数量）
- 图表懒加载（切换标签时才渲染）

### 3. 用户体验
- 加载状态提示（loading）
- 空数据提示（empty）
- 错误提示（error）
- 刷新按钮（更新数据）

### 4. 数据可视化
- 使用 ECharts 5.5.0（功能强大）
- 支持多种图表类型
- 支持图表交互（悬停、点击）
- 支持数据系列切换

## 📊 数据来源

### API 接口
```
GET /api/projects/{id}              # 项目详情
GET /api/tasks/search               # 任务列表
GET /api/iterations/query           # 迭代列表
GET /api/work-hours/project/{id}    # 工时记录
GET /api/statistics/trend           # 工时趋势
```

### 数据处理
```
原始数据 → 清洗 → 聚合 → 统计 → 可视化
```
