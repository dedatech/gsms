# 项目详情页概览模块 - 快速启动指南

## 快速开始

### 1. 启动服务

**启动后端（端口 8080）：**
```bash
cd backend
mvn spring-boot:run
```

**启动前端（端口 3000）：**
```bash
cd frontend
npm run dev
```

### 2. 访问概览模块

1. 登录系统（测试账号：`admin` / `Admin123`）
2. 进入项目列表页面
3. 点击任意项目进入项目详情页
4. 点击"概览"标签查看概览模块

## 功能演示

### 查看项目统计
- 顶部显示项目名称、状态、完成进度
- 查看剩余时间（< 3天橙色预警）
- 查看成员数和迭代数

### 查看任务指标
- **总任务数**：显示项目所有任务
- **已完成**：显示已完成任务和完成百分比
- **进行中**：显示正在进行的任务
- **已逾期**：显示已逾期的任务（红色警告）

### 查看迭代进度
- 横向滚动查看所有迭代
- 每个迭代显示状态图标、进度条、任务数
- 点击迭代卡片跳转到迭代详情

### 查看最近活动
- 按日期分组显示活动记录（今天/昨天/具体日期）
- 支持筛选活动类型（全部/任务/迭代/成员）
- 点击活动查看详情

### 快速操作
- **新建任务**：快速创建新任务
- **新建需求**：快速创建新需求
- **新建迭代**：快速创建新迭代

## 测试数据准备

### 创建测试项目
1. 进入项目列表页面
2. 点击"新建项目"按钮
3. 填写项目信息：
   - 项目名称：测试项目
   - 项目代码：TEST001
   - 项目状态：进行中
   - 计划结束时间：选择未来日期
4. 提交创建

### 创建测试迭代
1. 进入项目详情页
2. 点击"规划"标签
3. 点击"新建迭代"按钮
4. 填写迭代信息：
   - 迭代名称：Sprint 1
   - 迭代状态：进行中
   - 计划开始/结束时间
5. 提交创建

### 创建测试任务
1. 进入项目详情页
2. 点击"需求"或"迭代"标签
3. 点击"新建任务"按钮
4. 填写任务信息：
   - 任务标题：测试任务
   - 任务类型：需求/任务
   - 优先级：中
   - 任务状态：待办/进行中/已完成
   - 计划结束时间：设置不同日期测试逾期功能
5. 提交创建

## 常见问题

### Q1: 概览页面显示空白？
**A:** 确保项目已创建任务和迭代数据。如果没有数据，会显示空状态提示。

### Q2: 逾期任务计算不准确？
**A:** 检查任务的计划结束时间是否设置正确。逾期判断基于计划结束时间 < 当前日期。

### Q3: 迭代进度显示为0？
**A:** 迭代进度基于该迭代下的任务完成率计算。确保：
- 迭代已分配任务
- 任务已完成（状态为 DONE）

### Q4: 活动记录不显示？
**A:** 活动记录从操作日志表获取。确保：
- 已执行相关操作（创建、更新、删除）
- 操作日志模块正常工作

### Q5: 点击快速操作按钮没有反应？
**A:** 快速操作通过事件与父组件通信。确保父组件（ProjectDetail.vue）已正确实现事件处理函数。
