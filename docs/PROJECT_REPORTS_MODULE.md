# 项目报表分析模块

## 概述

项目报表分析模块是 TeamMaster 统领工时管理平台的核心功能之一，提供了全面的**进度、工时、团队和质量**四个维度的数据分析，帮助项目经理和团队成员更好地了解项目状态、优化资源分配、提升工作效率。

## 核心功能

### 1. 进度报表

#### 1.1 迭代完成率趋势（折线图）
- **功能**：展示项目迭代完成率的历史趋势
- **X轴**：时间（最近7天）
- **Y轴**：完成率（0-100%）
- **交互**：悬停显示具体日期的完成率数据
- **用途**：追踪项目整体进度，识别进度瓶颈

#### 1.2 任务状态分布（饼图）
- **功能**：展示项目中不同状态任务的占比
- **分类**：待办、进行中、已完成
- **交互**：点击图例隐藏/显示系列
- **用途**：快速了解项目整体健康度

#### 1.3 里程碑达成情况（甘特图）
- **功能**：展示项目各迭代的时间线
- **颜色编码**：
  - 绿色：已完成
  - 蓝色：进行中
  - 灰色：未开始
- **交互**：悬停显示详细日期信息
- **用途**：可视化项目进度，识别延期风险

#### 1.4 预计完成时间分析（散点图）
- **功能**：展示未完成任务的计划完成时间和预估工时
- **X轴**：计划完成时间
- **Y轴**：预估工时
- **颜色编码**：蓝色（进行中）、橙色（待办）
- **气泡大小**：预估工时
- **用途**：识别即将到期的任务，优化资源分配

### 2. 工时报表

#### 2.1 成员工时投入排行（柱状图）
- **功能**：展示成员工时投入排名（Top 10）
- **交互**：悬停显示具体工时数
- **用途**：识别高贡献成员，优化激励机制

#### 2.2 工时投入趋势（面积图）
- **功能**：展示项目工时投入的时间趋势
- **时间范围**：可自定义（7天/30天/本月/本季度/自定义）
- **交互**：悬停显示具体日期的工时数据
- **用途**：分析团队工作节奏，预测资源需求

#### 2.3 预估工时 vs 实际工时（散点图）
- **功能**：对比任务的预估工时和实际工时
- **X轴**：预估工时
- **Y轴**：实际工时
- **辅助线**：45度参考线（理想情况：预估=实际）
- **用途**：评估估时准确性，改进估时方法

#### 2.4 工时分布（按迭代）（柱状图）
- **功能**：展示各迭代的工时投入情况
- **交互**：悬停显示具体工时数
- **用途**：识别资源分配不均，优化迭代规划

### 3. 团队报表

#### 3.1 成员任务分布（堆叠柱状图）
- **功能**：展示各成员的任务状态分布
- **堆叠维度**：待办、进行中、已完成
- **交互**：悬停显示各状态任务数
- **用途**：识别负载不均，优化任务分配

#### 3.2 成员贡献度排行（雷达图）
- **功能**：综合评估成员贡献度
- **评估维度**：
  - 完成任务数量（权重×10）
  - 投入工时（权重×1）
- **交互**：悬停显示详细贡献数据
- **用途**：识别核心成员，优化激励机制

#### 3.3 成员负载分析（热力图）
- **功能**：展示成员当前负载情况
- **指标**：进行中任务数
- **颜色编码**：
  - 绿色：负载低（0-3个任务）
  - 黄色：负载中（4-6个任务）
  - 红色：负载高（7+个任务）
- **用途**：识别过载成员，预防团队疲劳

#### 3.4 成员活跃度趋势（面积图）
- **功能**：展示成员活跃度的时间趋势
- **指标**：每天有工时记录的成员数
- **交互**：悬停显示具体日期的活跃成员数
- **用途**：识别团队参与度波动，提升团队凝聚力

### 4. 质量报表

#### 4.1 缺陷数量趋势（折线图）
- **功能**：展示缺陷数量的时间趋势
- **交互**：悬停显示具体日期的缺陷数
- **用途**：识别质量波动，及时调整开发策略

#### 4.2 缺陷类型分布（饼图）
- **功能**：展示不同严重程度缺陷的占比
- **分类**：阻塞、严重、主要、次要、trivial
- **交互**：点击图例隐藏/显示系列
- **用途**：识别主要质量问题，制定改进计划

#### 4.3 缺陷修复时效（箱线图）
- **功能**：展示各缺陷的修复时长
- **颜色编码**：
  - 绿色：1天内（优秀）
  - 黄色：1-3天（良好）
  - 红色：3天以上（需改进）
- **交互**：悬停显示具体修复天数
- **用途**：评估缺陷响应速度，优化质量流程

#### 4.4 缺陷密度（按模块）（热力图）
- **功能**：展示各迭代的缺陷密度（缺陷数/任务数）
- **颜色编码**：
  - 绿色：密度低（0-20%）
  - 黄色：密度中（20-35%）
  - 红色：密度高（35%+）
- **用途**：识别质量薄弱环节，加强代码审查

## 技术实现

### 前端技术栈
- **Vue 3** - 渐进式 JavaScript 框架
- **TypeScript** - 类型安全
- **ECharts 5.5.0** - 数据可视化库
- **Element Plus** - UI 组件库
- **Day.js** - 日期处理库

### 组件结构
```
frontend/src/views/project/
└── ReportsView.vue          # 报表主视图组件
```

### API 接口
- `GET /api/projects/{id}` - 获取项目详情
- `GET /api/tasks/search` - 获取任务列表
- `GET /api/iterations/query` - 获取迭代列表
- `GET /api/work-hours/project/{id}` - 获取工时记录
- `GET /api/statistics/trend` - 获取工时趋势统计

### 数据流
```
1. 组件挂载 → 加载项目/任务/迭代/工时数据
2. 数据处理 → 统计分析、聚合计算
3. 图表渲染 → ECharts 可视化
4. 用户交互 → 时间范围筛选、报表切换
```

## 使用指南

### 基本使用

1. **访问报表模块**
   - 进入项目详情页
   - 点击顶部导航栏的"报表"标签

2. **切换报表类型**
   - 点击报表类型标签（进度/工时/团队/质量）
   - 系统自动渲染对应报表

3. **筛选时间范围**
   - 点击顶部时间范围选择器
   - 选择预设范围（7天/30天/本月/本季度）或自定义
   - 系统自动刷新数据

4. **查看详细数据**
   - 悬停在图表上显示详细数据
   - 点击图例隐藏/显示数据系列

5. **刷新数据**
   - 点击"刷新"按钮获取最新数据

6. **导出报表**
   - 点击"导出"按钮（功能开发中）

### 高级技巧

#### 1. 组合分析
- **进度 + 工时**：分析进度滞后的原因（工时投入不足？估时不准？）
- **团队 + 质量**：识别质量薄弱的成员（缺陷密度高？）
- **工时 + 质量**：评估质量成本（修复缺陷的工时占比）

#### 2. 趋势分析
- 关注迭代完成率趋势，识别进度瓶颈
- 关注工时投入趋势，预测资源需求
- 关注缺陷数量趋势，及时发现质量波动

#### 3. 对比分析
- 对比不同迭代的工时分布，优化迭代规划
- 对比成员负载，识别负载不均
- 对比缺陷密度，识别质量薄弱环节

## 常见问题

### Q1: 为什么某些图表没有数据？
**A**: 可能的原因：
- 项目刚创建，还没有相关数据
- 时间范围选择不当，导致数据为空
- 权限不足，无法查看某些数据

**解决方法**：调整时间范围，或联系管理员确认权限。

### Q2: 如何导出报表数据？
**A**: 目前导出功能正在开发中。未来支持：
- 导出为 PDF（包含所有图表）
- 导出为 Excel（原始数据表格）
- 导出为图片（单个图表）

### Q3: 工时趋势数据和工时分布数据不一致？
**A**: 正常现象。工时趋势按天统计工时总和，工时分布按迭代统计工时总和，两者统计维度不同。

### Q4: 如何自定义报表？
**A**: 目前不支持自定义报表。未来计划支持：
- 自定义图表类型
- 自定义数据维度
- 自定义时间粒度

### Q5: 图表显示不完整或样式错乱？
**A**: 可能的原因：
- 浏览器窗口太小
- 图表数据量过大

**解决方法**：
- 调整浏览器窗口大小
- 缩短时间范围，减少数据量
- 刷新页面
