# 项目报表分析模块 - 快速使用指南

## 一分钟上手

### 第一步：访问报表
1. 进入任意项目详情页
2. 点击顶部导航栏的 **"报表"** 标签

### 第二步：选择报表类型
点击以下任一标签查看对应报表：
- **进度报表** - 了解项目进度
- **工时报表** - 分析工时投入
- **团队报表** - 评估团队表现
- **质量报表** - 监控项目质量

### 第三步：筛选时间范围
点击右上角的时间范围选择器：
- 最近7天
- 最近30天
- 本月
- 本季度
- 自定义（选择具体日期范围）

## 常用场景

### 场景1：周会汇报项目进度
**操作步骤**：
1. 选择"进度报表"
2. 时间范围设置为"本月"
3. 查看"迭代完成率趋势"和"任务状态分布"
4. 点击"导出"保存报表（功能开发中）

**关键指标**：
- 迭代完成率
- 任务状态分布（待办/进行中/已完成）
- 里程碑达成情况

### 场景2：评估成员工时投入
**操作步骤**：
1. 选择"工时报表"
2. 时间范围设置为"本月"
3. 查看"成员工时投入排行"和"工时投入趋势"

**关键指标**：
- 成员工时投入排行（Top 10）
- 工时投入趋势（按天统计）
- 工时分布（按迭代）

### 场景3：优化任务分配
**操作步骤**：
1. 选择"团队报表"
2. 查看"成员任务分布"和"成员负载分析"

**关键指标**：
- 成员任务分布（待办/进行中/已完成）
- 成员负载分析（进行中任务数）
- 成员贡献度排行

### 场景4：质量复盘会议
**操作步骤**：
1. 选择"质量报表"
2. 时间范围设置为"本季度"
3. 查看"缺陷数量趋势"和"缺陷类型分布"

**关键指标**：
- 缺陷数量趋势
- 缺陷类型分布（按严重程度）
- 缺陷修复时效
- 缺陷密度（按模块）

## 图表交互

### 悬停查看详情
将鼠标悬停在图表上，显示详细数据：
- 折线图/面积图：具体日期的数据
- 柱状图：具体类别的数值
- 饼图：类别的名称、数值和百分比
- 散点图：数据点的详细信息

### 点击图例
点击图例可以隐藏/显示对应的数据系列，方便对比分析。

### 刷新数据
点击右上角的 **"刷新"** 按钮获取最新数据。

## 快捷技巧

### 技巧1：组合分析
- **进度 + 工时** → 发现进度滞后的原因
- **团队 + 质量** → 识别质量薄弱的成员
- **工时 + 质量** → 评估质量成本

### 技巧2：趋势分析
- 关注 **迭代完成率趋势**，识别进度瓶颈
- 关注 **工时投入趋势**，预测资源需求
- 关注 **缺陷数量趋势**，及时发现质量波动

### 技巧3：对比分析
- 对比不同迭代的工时分布，优化迭代规划
- 对比成员负载，识别负载不均
- 对比缺陷密度，识别质量薄弱环节

## 常见问题

### Q: 为什么某些图表没有数据？
**A**: 调整时间范围，或确认项目是否有相关数据。

### Q: 如何导出报表？
**A**: 点击"导出"按钮（功能开发中，敬请期待）。

### Q: 图表显示不完整怎么办？
**A**: 调整浏览器窗口大小，或缩短时间范围减少数据量。
