## 已知问题

### 问题1：vue-tsc 编译错误
**描述**：运行 `npm run build` 时 vue-tsc 报错

**解决方案**：
- 使用 `npx vite build` 跳过类型检查
- 或者升级 vue-tsc 到最新版本

### 问题2：图表数据为空
**描述**：某些图表没有数据

**解决方案**：
- 调整时间范围
- 确认项目是否有相关数据

### 问题3：图表显示不完整
**描述**：图表被截断或显示不完整

**解决方案**：
- 调整浏览器窗口大小
- 刷新页面
