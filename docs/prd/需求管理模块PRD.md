## 1. 文档概述

### 1.1 背景

当前项目详情页存在"需求"和"规划"两个标签页，功能职责不清晰，存在以下问题：

- 两个模块都有"新建需求"功能，入口重复
- 用户不清楚应该在哪个模块中创建需求
- 需求的生命周期管理不明确

### 1.2 目标

明确需求管理模块的职责定位，消除功能重叠，为用户提供清晰的需求管理体验。

### 1.3 范围

本PRD涵盖项目详情页中的需求管理功能，包括：

- 需求收集与展示
- 需求规划到迭代
- 需求编辑与管理
- 迭代管理

---

## 2. 产品定位

### 2.1 模块定位

**需求管理模块**是项目中需求的全生命周期管理中心，负责：

- 收集和整理需求
- **迭代管理**（需求的时间组织维度）
- 将需求分配到迭代
- 管理需求的执行进度

> **注意**：迭代管理不作为独立模块，而是需求管理的一部分。

### 2.2 用户角色

| 角色   | 职责              | 权限      |
| ---- | --------------- | ------- |
| 产品经理 | 创建需求、规划迭代、分配负责人 | 所有权限    |
| 项目经理 | 管理迭代、查看需求进度     | 所有权限    |
| 开发人员 | 查看需求、更新任务状态     | 只读+状态更新 |
| 测试人员 | 查看需求、创建缺陷       | 只读+创建缺陷 |

## 3. 功能需求

### 3.1 迭代管理（需求的时间维度）

#### 功能描述

迭代是需求规划的时间组织单位，在需求管理模块中统一管理。

> **说明**：迭代管理不作为独立模块，而是需求管理的一部分。

#### 功能列表

| 功能      | 描述           | 优先级 |
| ------- | ------------ | --- |
| 迭代列表    | 展示项目所有迭代及其进度   | P0  |
| 创建迭代    | 新建迭代并设置名称和时间范围  | P0  |
| 编辑迭代    | 修改迭代名称、时间范围等   | P1  |
| 删除迭代    | 删除未开始的迭代     | P1  |
| 迭代状态切换  | 未开始 ↔ 进行中 ↔ 已完成  | P1  |
| 迭代选择    | 切换当前查看的迭代     | P0  |

#### 交互说明

- 左侧：迭代列表，可展开查看需求
- 点击迭代卡片：选中该迭代，右侧显示其需求
- 迭代卡片显示：名称、状态、时间范围、进度条、需求数量

### 3.2 需求池

#### 功能描述

展示项目中所有待规划的需求，支持筛选和搜索。

#### 功能列表

| 功能     | 描述                          | 优先级 |
| ------ | --------------------------- | --- |
| 需求列表展示 | 以卡片形式展示所有需求，显示标题、优先级、负责人、状态 | P0  |
| 需求筛选   | 按状态、负责人、迭代进行筛选              | P1  |
| 需求搜索   | 按标题关键词搜索需求                  | P1  |
| 查看详情   | 点击需求卡片查看完整信息                | P0  |

#### 交互说明

- 需求池为只读视图，不支持直接编辑
- 点击需求卡片跳转到需求详情页面
- 详情页面支持编辑功能

### 3.2 需求规划

#### 功能描述

将需求分配到迭代，设置执行计划。

#### 功能列表

| 功能      | 描述           | 优先级 |
| ------- | ------------ | --- |
| 迭代列表    | 展示所有迭代及其进度   | P0  |
| 分配需求到迭代 | 通过拖拽将需求分配到迭代 | P0  |
| 快速添加需求  | 在迭代下直接创建需求   | P0  |
| 编辑迭代    | 修改迭代名称、时间范围等 | P1  |
| 删除迭代    | 删除未开始的迭代     | P1  |
| 启动迭代    | 标记迭代为"进行中"   | P1  |
| 完成迭代    | 标记迭代为"已完成"   | P1  |

#### 交互说明

- 左侧：迭代列表，可展开查看需求
- 右侧：未规划需求池，可拖拽到左侧迭代
- 支持在迭代中直接新建需求（输入需求名称，回车创建）

### 3.3 需求编辑

#### 功能描述

支持对需求的基本信息进行编辑。

#### 功能列表

| 功能     | 描述            | 优先级 |
| ------ | ------------- | --- |
| 编辑需求标题 | 修改需求标题        | P0  |
| 编辑需求描述 | 修改需求详细描述      | P0  |
| 设置优先级  | 设置需求的高/中/低优先级 | P0  |
| 分配负责人  | 指定需求的负责人      | P0  |
| 设置关联迭代 | 将需求关联到指定迭代    | P0  |
| 删除需求   | 删除不需要的需求      | P1  |

#### 交互说明

- 点击需求卡片进入详情页面
- 详情页面为可编辑表单
- 支持保存和取消操作

## 5. 交互流程

### 5.1 新建需求流程

```
用户点击"添加需求"按钮
    ↓
显示输入框
    ↓
用户输入需求名称，按回车
    ↓
系统创建需求（状态：待规划，关联到当前迭代）
    ↓
需求出现在迭代的需求列表中
```

### 5.2 需求分配流程

```
用户从右侧未规划需求池拖拽需求
    ↓
拖拽到左侧目标迭代区域
    ↓
释放鼠标
    ↓
系统更新需求的迭代关联
    ↓
需求从未规划区域消失，出现在迭代需求列表中
```

### 5.3 需求查看流程

```
用户点击需求卡片
    ↓
跳转到需求详情页面
    ↓
显示需求完整信息（标题、描述、优先级、负责人、迭代等）
    ↓
用户可编辑需求信息
    ↓
保存后返回
```

## 7. 状态流转

### 7.1 需求状态

```
┌──────────────────────────────────────────────┐
│  需求状态流转                                   │
│                                               │
│   [待规划] ─────→ [进行中] ─────→ [已完成]   │
│      ↑              ↑            │          │
│      └──────────────┘            │          │
│         重新规划                        │          │
└──────────────────────────────────────────────┘

状态说明：
- 待规划：需求已创建，尚未分配到迭代
- 进行中：需求已分配到迭代，迭代进行中
- 已完成：需求已完成开发，待验收
```

### 7.2 迭代状态

```
┌──────────────────────────────────────────────┐
│  迭代状态流转                                   │
│                                               │
│  [未开始] ──→ [进行中] ──→ [已完成]           │
│     ↑            │          │                │
│     └────────────┘          │                │
│        重新开始               │                │
└──────────────────────────────────────────────┘
```

## 8. 非功能需求

### 8.1 性能需求

- 需求列表加载时间 < 1秒
- 拖拽操作响应时间 < 200ms

### 8.2 安全需求

- 只有项目成员可以查看项目需求
- 只有项目经理/产品经理可以编辑需求
- 删除操作需要二次确认

### 8.3 兼容性需求

- 支持主流浏览器（Chrome、Firefox、Safari）
- 响应式设计，支持1920x1080及以上分辨率
