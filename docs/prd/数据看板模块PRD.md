## 1. 文档概述

### 1.1 背景

原项目详情页存在"概览"和"报表"两个标签页，功能定位存在重叠：

- 概览页展示项目统计和迭代进度
- 报表页提供多维度数据分析
- 两者都是数据展示，区分度不高

### 1.2 目标

将概览和报表合并为"数据看板"模块，提供统一的项目数据分析入口。

### 1.3 范围

本PRD涵盖项目详情页中的数据分析功能，包括：

- 项目关键指标展示
- 迭代进度跟踪
- 多维度数据图表
- 报表导出功能

---

## 2. 产品定位

### 2.1 模块定位

**数据看板模块**是项目数据的统一展示中心，负责：

- 展示项目整体状态和关键指标
- 提供多维度数据分析图表
- 支持数据导出和报表生成

### 2.2 用户角色

| 角色   | 职责           | 权限  |
| ---- | -------------- | ----- |
| 项目经理 | 查看所有数据、导出报表 | 所有权限 |
| 团队成员 | 查看项目数据     | 只读   |

## 3. 功能需求

### 3.1 项目概览

#### 功能描述

展示项目整体状态和关键指标，作为数据看板的首屏。

#### 功能列表

| 功能     | 描述                          | 优先级 |
| ------ | --------------------------- | --- |
| 项目状态   | 显示项目名称、状态标签               | P0  |
| 完成进度   | 进度条显示任务完成百分比             | P0  |
| 剩余时间   | 显示项目剩余天数，逾期预警             | P0  |
| 关键指标   | 总任务数、已完成、进行中、已逾期（可点击跳转） | P0  |
| 快捷入口   | 点击指标卡片跳转到对应详细视图          | P1  |

#### 交互说明

```
┌─────────────────────────────────────────────────────┐
│  [项目名称]                    [项目状态标签]    │
│                                                 │
│  完成进度 ████████████░░░░  75%                │
│                                                 │
│  剩余时间: 15天                                  │
│                                                 │
│  ┌─────────┬─────────┬─────────┬─────────┐     │
│  │ 总任务数  │ 已完成   │ 进行中   │ 已逾期   │     │
│  │   50    │   38    │    8    │    4    │     │
│  └─────────┴─────────┴─────────┴─────────┘     │
└─────────────────────────────────────────────────────┘
```

### 3.2 迭代进度

#### 功能描述

以时间轴形式展示项目所有迭代及其进度。

#### 功能列表

| 功能     | 描述                          | 优先级 |
| ------ | --------------------------- | --- |
| 迭代时间轴  | 按时间顺序展示所有迭代              | P0  |
| 迭代状态   | 显示每个迭代的状态（未开始/进行中/已完成）    | P0  |
| 迭代进度条  | 显示迭代内任务完成百分比             | P0  |
| 查看详情   | 点击迭代卡片查看详细信息              | P1  |

#### 交互说明

```
┌──────────────────────────────────────────────────────┐
│  迭代进度                                 [查看全部] │
│  ┌────────────────────────────────────────────────┐  │
│  │ ✓ #1 项目一期        已完成     100%  │  │
│  │ ▶ #2 项目二期        进行中      60%   │  │
│  │ ⏰ #3 项目三期        未开始      0%    │  │
│  └────────────────────────────────────────────────┘  │
└───────────────────────────────────────────────────────┘
```

### 3.3 报表分析

#### 功能描述

提供多维度数据报表，支持时间范围筛选和数据导出。

#### 功能列表

| 功能     | 描述                          | 优先级 |
| ------ | --------------------------- | --- |
| 进度报表   | 迭代完成率趋势、任务状态分布、里程碑达成   | P0  |
| 工时报表   | 成员工时投入、工时趋势、预估vs实际、工时分布 | P0  |
| 团队报表   | 成员任务分布、成员工时投入           | P1  |
| 时间范围筛选 | 支持7天/30天/本月/本季度/自定义      | P0  |
| 报表导出   | 支持导出为Excel/PDF格式            | P1  |

#### 交互说明

- 顶部：报表类型切换标签（进度报表/工时报表/团队报表）
- 左侧：时间范围选择器 + 自定义日期选择
- 右侧：刷新 + 导出按钮
- 主体：图表区域，使用ECharts渲染

### 3.4 图表类型

#### 进度报表

| 图表名称 | 图表类型 | 说明 |
|---------|---------|------|
| 迭代完成率趋势 | 折线图 | 各迭代完成率变化 |
| 任务状态分布 | 饼图 | 待办/进行中/已完成占比 |
| 里程碑达成情况 | 柱状图 | 计划vs实际里程碑 |
| 预计完成时间分析 | 散点图 | 任务预计完成时间分布 |

#### 工时报表

| 图表名称 | 图表类型 | 说明 |
|---------|---------|------|
| 成员工时投入排行 | 横向柱状图 | 按成员统计工时 |
| 工时投入趋势 | 折线图 | 工时随时间变化 |
| 预估工时vs实际工时 | 对比柱状图 | 评估工时准确性 |
| 工时分布（按迭代）| 堆叠柱状图 | 各迭代工时投入 |

#### 团队报表

| 图表名称 | 图表类型 | 说明 |
|---------|---------|------|
| 成员任务分布 | 热力图 | 成员任务负载分布 |
| 成员工时投入 | 雷达图 | 成员工时投入对比 |

## 5. 交互流程

### 5.1 数据查看流程

```
用户进入数据看板
    ↓
默认显示：项目概览 + 迭代进度 + 进度报表
    ↓
用户可切换报表类型（进度/工时/团队）
    ↓
图表更新为对应类型的内容
    ↓
用户可选择时间范围筛选数据
```

### 5.2 报表导出流程

```
用户点击"导出"按钮
    ↓
弹出导出选项对话框（Excel/PDF）
    ↓
选择格式和报表内容
    ↓
系统生成文件并下载
```

### 5.3 指标跳转流程

```
用户点击关键指标卡片
    ↓
跳转到对应详细视图
    ↓
- 点击"已逾期" → 跳转到任务执行并筛选逾期任务
- 点击"进行中" → 跳转到任务执行并筛选进行中任务
- 点击迭代卡片 → 跳转到需求管理并选中该迭代
```

## 6. 数据需求

### 6.1 需要的数据接口

| 接口/数据 | 说明 | 优先级 |
|---------|------|------|
| 项目基本信息 | 名称、状态、开始/结束时间 | P0 |

| 迭代列表 | 所有迭代及进度数据 | P0 |

| 任务状态分布 | 各状态任务数量统计 | P0 |

## 7. 非功能需求

### 7.1 性能需求

- 首屏数据加载时间 < 2秒
- 图表渲染时间 < 1秒
- 报表导出时间 < 5秒

### 7.2 安全需求

- 只有项目成员可以查看项目数据
- 导出功能需要相应权限

### 7.3 兼容性需求

- 支持主流浏览器（Chrome、Firefox、Safari）
- 响应式设计，支持1920x1080及以上分辨率
- 图表自适应不同屏幕尺寸
