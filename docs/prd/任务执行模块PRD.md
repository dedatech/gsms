## 1. 文档概述

### 1.1 背景

任务执行是项目开发的核心环节，需要清晰的进度跟踪和高效的工作流管理。

### 1.2 目标

提供清晰的任务执行视图，支持开发人员高效完成工作。

### 1.3 范围

本PRD涵盖项目详情页中的任务执行功能，包括：

- 任务看板视图
- 任务列表视图
- 任务筛选与搜索
- 任务详情查看

---

## 2. 产品定位

### 2.1 模块定位

**任务执行模块**是项目中所有工作项的统一管理中心，负责：

- 任务分解与执行跟踪
- 缺陷记录与修复验证
- 工作项状态流转
- 工时记录与统计

### 2.2 用户角色

| 角色   | 职责              | 权限      |
| ---- | --------------- | ------- |
| 项目经理 | 分配任务、查看进度     | 所有权限    |
| 开发人员 | 承接任务、更新状态、记录工时 | 编辑+状态更新 |
| 其他成员 | 查看任务进度       | 只读      |

## 3. 功能需求

### 3.1 任务列表

#### 功能描述

以列表/看板形式展示所有任务，支持筛选和搜索。

#### 功能列表

| 功能     | 描述                          | 优先级 |
| ------ | --------------------------- | --- |
| 任务列表   | 以表格形式展示所有任务              | P0  |
| 看板视图   | 按状态分列展示任务                | P1  |
| 需求分组   | 任务按所属需求分组显示（可选）            | P1  |
| 状态筛选   | 按状态筛选任务                    | P1  |
| 负责人筛选  | 按负责人筛选                      | P1  |
| 优先级筛选  | 按优先级筛选                      | P1  |
| 任务搜索   | 按标题关键词搜索                    | P1  |

#### 交互说明

- 顶部工具栏：筛选条件 + 搜索框 + 新建按钮
- 主体区域：任务列表/看板，支持拖拽更新状态
- 任务卡片显示：标题、类型标签、优先级、负责人、工时

### 3.2 任务管理

#### 功能描述

基于需求创建任务，跟踪任务执行进度。

#### 功能列表

| 功能      | 描述           | 优先级 |
| ------- | ------------ | --- |
| 新建任务    | 从需求分解创建任务    | P0  |
| 编辑任务    | 修改任务标题、描述等   | P0  |
| 分配负责人   | 指定任务执行人      | P0  |
| 设置优先级   | 高/中/低优先级     | P0  |
| 记录工时    | 填写实际工时       | P1  |
| 关联需求    | 将任务关联到需求     | P0  |
| 删除任务    | 删除误创建的任务      | P1  |
| 任务状态流转  | 待办→进行中→已完成    | P0  |

#### 交互说明

- 点击需求卡片「+ 创建任务」按钮：弹出创建对话框，自动关联需求
- 拖拽任务卡片：在不同状态列之间拖拽更新状态
- 点击任务卡片：查看任务详情

### 3.3 详情查看

#### 功能描述

点击任务卡片查看完整信息。

#### 功能列表

| 功能     | 描述          | 优先级 |
| ------ | ----------- | --- |
| 查看详情   | 显示任务完整信息    | P0  |
| 编辑信息   | 可编辑各字段内容    | P0  |
| 查看工时记录 | 显示关联的工时记录列表 | P1  |
| 添加工时记录 | 快速填写实际工时    | P1  |
| 查看操作历史 | 显示状态变更历史    | P2  |

## 5. 交互流程

### 5.1 新建任务流程

```
用户点击"新建工作项"
    ↓
选择类型：任务
    ↓
填写任务信息（标题、描述、关联需求等）
    ↓
保存
    ↓
任务出现在"待办"列，显示在对应需求下
```

### 5.2 新建缺陷流程

```
用户点击"新建工作项"
    ↓
选择类型：缺陷
    ↓
填写缺陷信息（标题、严重程度、复现步骤等）
    ↓
保存
    ↓
缺陷出现在"待办"列，带有红色缺陷标签
```

### 5.3 状态更新流程

```
用户拖拽工作项卡片
    ↓
从当前状态列拖到目标状态列
    ↓
释放鼠标
    ↓
系统更新工作项状态
    ↓
卡片出现在新状态列中
```

## 6. 数据模型

### 6.1 任务字段

| 字段             | 类型      | 必填  | 说明                         |
| ------------- | ------- | --- | -------------------------- |
| id             | Long    | ✅   | 任务唯一标识                     |
| title          | String  | ✅   | 任务标题                       |
| description    | String  | ❌   | 任务详细描述                     |
| type           | Enum    | ✅   | 类型（REQUIREMENT/TASK/BUG）        |
| priority       | Enum    | ✅   | 优先级（LOW/MEDIUM/HIGH）       |
| status         | Enum    | ✅   | 状态                         |
| assigneeId     | Long    | ❌   | 负责人ID                      |
| iterationId    | Long    | ❌   | 关联迭代ID                     |
| parentId       | Long    | ❌   | 父任务ID（任务关联到需求）           |
| planStartDate  | Date    | ❌   | 计划开始日期                     |
| planEndDate    | Date    | ❌   | 计划结束日期                     |
| estimateHours  | Decimal | ❌   | 预估工时                       |
| actualHours   | Decimal | ❌   | 实际工时（从工时记录汇总）            |
| remainingHours | Decimal | ❌   | 剩余工时（预估工时 - 实际工时）        |
| projectId     | Long    | ✅   | 所属项目ID                     |

## 7. 状态流转

### 7.1 状态枚举（与后端 TaskStatus 一致）

| 枚举值 | Code | 显示文本  | 说明     |
| ------ | ---- | ----- | ------ |
| TODO | 1 | 待处理   | 初始状态   |
| IN_PROGRESS | 2 | 进行中   | 正在执行   |
| DONE | 3 | 已完成   | 完成状态   |
| CLOSED | 6 | 已关闭   | 最终关闭   |

### 7.2 任务状态流转

```
┌──────────────────────────────────────────────┐
│  任务状态流转                                   │
│                                               │
│  [待处理] ──→ [进行中] ──→ [已完成] ──→ [已关闭] │
│                                               │
└──────────────────────────────────────────────┘

状态说明：
- 待处理(TODO)：已创建但未开始执行
- 进行中(IN_PROGRESS)：正在开发中
- 已完成(DONE)：开发完成，待验收
- 已关闭(CLOSED)：验收通过，正式关闭
```

## 8. 非功能需求

### 8.1 性能需求

- 看板数据加载时间 < 1秒
- 拖拽操作响应时间 < 200ms
- 状态更新实时同步

### 8.2 安全需求

- 只有项目成员可以查看工作项
- 只有负责人/项目经理可以更新状态
- 删除操作需要二次确认

### 8.3 兼容性需求

- 支持主流浏览器（Chrome、Firefox、Safari）
- 响应式设计，支持1920x1080及以上分辨率
