## 1. 文档概述

### 1.1 背景

项目需要团队成员协作，成员管理是项目组织的基础功能。

### 1.2 目标

提供清晰的项目成员管理界面，支持成员添加、角色管理和贡献度跟踪。

### 1.3 范围

本PRD涵盖项目详情页中的成员管理功能，包括：

- 成员列表展示
- 成员角色管理
- 成员贡献度统计
- 成员任务分配

---

## 2. 产品定位

### 2.1 模块定位

**成员管理模块**是项目人员组织中心，负责：

- 查看和管理项目成员
- 设置成员角色权限
- 查看成员贡献度
- 为成员分配任务

### 2.2 用户角色

| 角色   | 职责           | 权限      |
| ---- | -------------- | ------- |
| 项目经理 | 添加/移除成员、更改角色、分配任务 | 所有权限    |
| 普通成员 | 查看其他成员信息、查看自己统计数据  | 只读      |
| 只读访客 | 仅查看项目基本信息     | 只读      |

### 3.4 角色管理

#### 功能描述

支持设置和更改成员角色，控制成员访问权限。

#### 角色定义

| 角色     | 权限说明         | 标签颜色 |
|-------|--------------|---------|
| 项目管理员 | 添加/移除成员、更改角色、分配任务 | 红色    |
| 普通成员   | 正常参与项目、填报工时     | 默认    |
| 只读访客   | 仅查看项目基本信息       | 蓝色    |

#### 功能列表

| 功能      | 描述           | 优先级 |

| 更改角色    | 修改现有成员的角色      | P0  |
| 移除成员    | 从项目中移除成员       | P0  |

## 5. 交互流程

### 5.1 添加成员流程

```
项目经理点击"添加成员"
    ↓
弹出选择用户对话框
    ↓
从用户列表中搜索并选择用户
    ↓
选择角色类型（项目管理员/普通成员/只读访客）
    ↓
确认添加
    ↓
系统发送邀请并添加到项目
    ↓
新成员出现在成员列表中
```

### 5.2 更改角色流程

```
点击成员卡片"更多" → "更改角色"
    ↓
弹出更改角色对话框
    ↓
显示当前角色和新角色选择
    ↓
选择新角色并确认
    ↓
系统更新成员角色
    ↓
成员列表中的角色标签更新
```

### 5.3 移除成员流程

```
点击成员卡片"更多" → "移除成员"
    ↓
弹出确认对话框
    ↓
用户确认移除
    ↓
系统从项目中移除该成员
    ↓
成员从成员列表中消失
```

## 6. 数据模型

### 6.1 成员字段（ProjectMember）

| 字段        | 类型    | 必填  | 说明             |
| --------- | ----- | --- | -------------- |
| id        | Long  | ✅   | 成员关系ID         |
| projectId | Long  | ✅   | 项目ID           |
| userId    | Long  | ✅   | 用户ID           |
| roleType  | Int   | ✅   | 角色类型（1=管理员,2=成员,3=访客）|
| updateTime | Date | ✅   | 更新时间           |

### 6.2 统计数据字段

| 字段        | 类型    | 来源     |
| --------- | ----- | ------ |
| taskCount   | Int   | 任务统计   |
| totalHours  | Decimal | 总工时统计 |
| weekHours   | Decimal | 本周工时统计 |
| monthHours  | Decimal | 本月工时统计 |

## 7. 贡献度计算

### 7.1 计算规则

贡献度基于成员完成的任务数量计算：

| 完成任务数   | 贡献度 | 星级显示 |
| --------- | ------ | ------- |
| ≥20       | 5级    | ★★★★★ |
| 15-19     | 4级    | ★★★★☆ |
| 10-14     | 3级    | ★★★☆☆ |
| 5-9       | 2级    | ★★☆☆☆ |
| 1-4       | 1级    | ★☆☆☆☆ |
| 0         | 0级    | 暂无贡献 |

### 7.2 显示规则

- 星级使用不同颜色区分：活跃成员(金色) vs 普通成员(灰色)
- 鼠标悬停显示具体完成数量

## 8. 非功能需求

### 8.1 性能需求

- 成员列表加载时间 < 1秒
- 卡片网格响应式布局流畅
- 搜索筛选响应时间 < 300ms

### 8.2 安全需求

- 只有项目管理员可以添加/移除成员
- 只有项目管理员可以更改成员角色
- 移除成员需要二次确认

### 8.3 兼容性需求

- 支持主流浏览器（Chrome、Firefox、Safari）
- 响应式设计，支持768px及以上分辨率
- 成员卡片网格自适应
