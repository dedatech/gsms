# 任务模块使用指南

## 快速开始

### 访问路径

1. 从项目列表选择一个项目
2. 进入项目详情页
3. 点击顶部导航栏的"任务"标签

### 界面布局

```
┌────────────┬──────────────────────┬────────────┐
│            │                      │            │
│   迭代树   │    工作项列表        │  详情面板   │
│            │                      │            │
│  (280px)   │      (自适应)        │  (400px)   │
│            │                      │            │
└────────────┴──────────────────────┴────────────┘
```

## 功能说明

### 左栏：迭代树

#### 查看迭代
- **全部节点**：显示项目内所有工作项
- **迭代节点**：显示该迭代下的工作项
- **任务数量**：每个节点右上角显示任务总数

#### 展开分组
- 点击迭代名称右侧的 `>` 图标展开
- 按类型分组显示：
  - 📋 需求
  - ✅ 任务
  - 🐞 缺陷

#### 拖拽操作
- 按住中栏的工作项
- 拖拽到左栏的迭代节点
- 松开鼠标完成移动

### 中栏：工作项列表

#### 视图模式

**1. 列表视图（默认）**
- 表格形式展示所有工作项
- 显示字段：编号、标题、类型、状态、负责人、迭代、优先级
- 支持排序和分页

**2. 看板视图**
- 按状态分为三列：
  - 🟠 待办
  - 🔵 进行中
  - 🟢 已完成
- 卡片显示关键信息
- 支持拖拽卡片到不同列

**3. 树形视图**
- 以需求为根节点
- 显示子任务层级关系
- 可展开/收起子任务

#### 筛选功能

**关键词搜索**
- 搜索工作项编号
- 搜索工作项标题

**类型筛选**
- 全部：显示所有类型
- 任务：仅显示任务
- 需求：仅显示需求
- 缺陷：仅显示缺陷

**迭代筛选**
- 点击左栏的迭代节点
- 中栏自动过滤该迭代的工作项

#### 工作项操作

**查看详情**
- 点击工作项行
- 右栏显示详情面板

**编辑工作项**
- 点击"编辑"按钮
- 打开编辑对话框

**删除工作项**
- 点击"删除"按钮
- 确认后删除

### 右栏：详情面板

#### 显示内容

**基本信息**
- 📝 工作项编号：如 `#123`
- 📌 标题：工作项标题
- 🏷️ 状态：可点击修改

**负责人**
- 头像和姓名
- 未分配时显示"未分配"

**描述**
- 完整的工作项描述
- 支持多行文本

**关联关系**
- 父级需求：点击可跳转

**工时信息**
- 预估工时：计划的小时数
- 实际工时：已用的小时数

**元数据**
- 创建时间
- 更新时间

#### 快捷操作

**修改状态**
- 点击状态标签
- 选择新状态
- 自动保存

**关闭面板**
- 点击右上角 ✕ 按钮
- 或按 `Esc` 键

## 常见操作

### 创建工作项

1. 点击中栏工具栏的"新建工作项"按钮
2. 或按快捷键 `N`
3. 填写表单：
   - 选择类型（需求/任务/缺陷）
   - 选择所属迭代（可选）
   - 选择父级任务（可选，仅需求可作父级）
   - 输入标题（必填）
   - 输入描述（可选）
   - 选择优先级
   - 选择状态
   - 选择负责人
   - 输入预估工时
4. 点击"确定"

### 创建迭代

1. 点击左栏顶部的 ➕ 按钮
2. 填写表单：
   - 迭代名称（必填）
   - 迭代描述（可选）
   - 计划开始时间（可选）
   - 计划结束时间（可选）
3. 点击"确定"

### 移动工作项到迭代

**方法 1：拖拽**
1. 在左栏选择目标迭代
2. 在中栏找到要移动的工作项
3. 拖拽工作项到左栏的迭代节点

**方法 2：编辑**
1. 打开工作项详情
2. 点击"编辑"按钮
3. 修改"所属迭代"字段
4. 点击"确定"

### 修改工作项状态

**方法 1：拖拽（看板视图）**
1. 切换到看板视图
2. 拖拽工作项卡片到目标状态列

**方法 2：详情面板**
1. 点击工作项查看详情
2. 点击状态标签
3. 选择新状态

**方法 3：编辑**
1. 打开工作项详情
2. 点击"编辑"按钮
3. 修改"状态"字段
4. 点击"确定"

### 搜索工作项

1. 点击搜索框（或按 `F` 键）
2. 输入关键词（编号或标题）
3. 列表自动过滤

### 筛选工作项

1. 点击类型筛选下拉框
2. 选择目标类型
3. 列表自动过滤

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `N` | 新建工作项 |
| `F` | 聚焦搜索框 |
| `Esc` | 关闭详情面板 |

## 最佳实践

### 工作流建议

1. **规划阶段**
   - 创建迭代
   - 创建需求（作为父级）
   - 为需求分配任务

2. **执行阶段**
   - 使用看板视图跟踪进度
   - 拖拽卡片更新状态
   - 及时填写预估工时

3. ** review 阶段**
   - 使用列表视图查看所有工作项
   - 筛选已完成的工作项
   - 检查工时记录

### 数据组织

1. **迭代管理**
   - 按时间周期创建迭代（如每周）
   - 为迭代设置明确的起止时间
   - 定期回顾迭代完成情况

2. **层级关系**
   - 使用需求作为父级
   - 将大任务分解为子任务
   - 保持层级不超过 3 层

3. **状态管理**
   - 及时更新工作项状态
   - 避免长期停留在"进行中"
   - 完成后及时标记为"已完成"

## 常见问题

### Q: 为什么看不到某些工作项？

**A:** 检查以下几点：
1. 是否应用了类型筛选
2. 是否选择了特定迭代
3. 是否使用了关键词搜索

### Q: 拖拽功能不生效？

**A:** 确保以下条件：
1. 使用看板视图拖拽状态
2. 使用左栏拖拽到迭代
3. 浏览器支持 HTML5 拖拽 API

### Q: 如何批量操作工作项？

**A:** 当前版本支持：
1. 勾选多个工作项
2. 批量删除（开发中）

更多批量操作功能即将推出。

### Q: 工时统计不准确？

**A:** 工时功能正在完善中：
1. 预估工时：手动输入
2. 实际工时：从工时记录表计算（开发中）
