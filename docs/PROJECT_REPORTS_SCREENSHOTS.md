## 🎯 使用场景示例

### 场景1：周会汇报项目进度
```
步骤：
1. 打开项目详情页
2. 点击"报表"标签
3. 确认显示"进度报表"
4. 时间范围选择"本周"
5. 查看"迭代完成率趋势"和"任务状态分布"

汇报要点：
- 本周迭代完成率从 60% 提升到 75%
- 任务状态：待办 30%、进行中 40%、已完成 30%
- 里程碑按计划推进，无延期风险
```

### 场景2：评估成员工时投入
```
步骤：
1. 点击"工时报表"标签
2. 时间范围选择"本月"
3. 查看"成员工时投入排行"

分析要点：
- 张三投入 120h，贡献最大
- 李四投入 95h，表现良好
- 王五投入 78h，符合预期
- 考虑给予张三和李四额外激励
```

### 场景3：优化任务分配
```
步骤：
1. 点击"团队报表"标签
2. 查看"成员负载分析"

分析要点：
- 张三：10个进行中任务（负载高，红色）
- 李四：5个进行中任务（负载中，黄色）
- 王五：2个进行中任务（负载低，绿色）

优化建议：
- 将张三的部分任务分配给王五
- 避免张三过度疲劳
```

### 场景4：质量复盘会议
```
步骤：
1. 点击"质量报表"标签
2. 时间范围选择"本季度"
3. 查看"缺陷类型分布"和"缺陷密度"

分析要点：
- 主要缺陷占比 40%，需要关注
- 迭代3的缺陷密度最高（35%）
- 缺陷修复时效：平均 2.5 天

改进计划：
- 加强迭代3的代码审查
- 优化主要缺陷的修复流程
- 提升缺陷响应速度
```

## 💡 交互说明

### 悬停查看详情
```
操作：鼠标悬停在图表上
效果：显示详细数据
示例：
- 折线图：显示具体日期的数据
- 饼图：显示类别的名称、数值和百分比
- 柱状图：显示具体类别的数值
```

### 点击图例
```
操作：点击图例
效果：隐藏/显示对应的数据系列
示例：
- 点击"已完成"图例 → 隐藏已完成系列
- 再次点击 → 显示已完成系列
```

### 刷新数据
```
操作：点击右上角"刷新"按钮
效果：重新加载数据，更新图表
```

## 🔍 图表说明

### 颜色编码
```
绿色 (#52c41a) ────────► 已完成 / 正常 / 低负载
蓝色 (#1890ff) ─────────► 进行中 / 默认
橙色 (#faad14) ─────────► 待办 / 警告 / 中负载
红色 (#f5222d) ──────────► 严重 / 危险 / 高负载
灰色 (#d9d9d9) ─────────► 未开始 / 禁用
```

### 图表类型
```
折线图/面积图 ─────────► 展示趋势
饼图 ──────────────────► 展示占比
柱状图 ────────────────► 对比大小
散点图 ────────────────► 展示关系
甘特图 ────────────────► 展示时间线
雷达图 ────────────────► 多维对比
```
